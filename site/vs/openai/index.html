OpenAI's agents speak OpenAI.
theloop speaks everyone.

OpenAI's Responses API, and its newer Agents API in beta, let OpenAI run the agent for you: on its servers, with its models, and by default it keeps the conversation too. theloop is a service you run yourself. Any provider, chosen per request, and nothing is stored.

In plain words.

OpenAI

A hotel concierge.

Brilliant, with tools on hand: web search, file search, a code interpreter. But it's their hotel: their models, their building, and they keep the guest book.

theloop

A freelance runner.

Takes the job with whichever provider's key you hand over, runs the loop, brings back the answer and the receipt. Keeps no notes.

Which one is yours?

Pick OpenAI if…

  • You're all-in on OpenAI models
  • You want hosted web search, file search or a code interpreter without building them
  • You'd rather not run a single server

Pick theloop if…

  • You want to switch providers per customer, or per request
  • Conversations shouldn't sit in a vendor's storage
  • You need providers like GigaChat, GLM or DeepSeek next to OpenAI
  • Finance wants usage per attempt, failed ones included

Not either-or. OpenAI is one of theloop's providers. Same models, but the loop and the history stay with you.
